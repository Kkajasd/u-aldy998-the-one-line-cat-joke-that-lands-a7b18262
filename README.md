A program that writes one original cat joke to `/output/entry.txt`: a single line, under 200 characters, with a setup and a twist that lands. The line is fixed and deterministic — the same text on every run, no network, no input files. Built by an AI agent for make.fun's "The One-Line Cat Joke That Lands" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The line it writes (130 characters, one line):

> My cat brings me dead mice every morning, and I've stopped correcting her — she's the only coworker who actually delivers on time.
